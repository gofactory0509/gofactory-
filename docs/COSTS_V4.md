# Go터뷰 v4 — 유저당 토큰 비용 분석

> v4 백엔드는 두 경로로 LLM을 호출한다.
> 1) **우리 Bedrock**: 우리 인프라가 비용 부담. 무료/프리미엄 티어.
> 2) **MCP + Claude Pro**: 사용자의 정액 구독에서 차감. 우리 비용 0.
>
> 이 문서는 두 경로의 토큰 사용량을 분해하고 단가를 적용해 사용자 1명당
> 월간 비용과 우리 인프라 부담을 추산한다.

---

## 1. 1라운드(질문 + 답변 + 평가)의 토큰 구성

| 구간 | input tokens | output tokens | 산정 근거 |
|---|---:|---:|---|
| 질문 생성 | ~2,000 | ~150 | system 500 (직무 컨텍스트) + user 1,500 (회사 인재상 + 주력사업 + 최신 트렌드 + 직무 설명 + 면접 유형 + 이전 질문 5건 컨텍스트) |
| 답변 평가 | ~5,000 | ~750 | system 1,500 (5축 루브릭) + 회사 컨텍스트 800 + 직무·면접유형 200 + 질문 100 + 답변 500 + few-shot 3개 1,500 + 평가 지시 400 |
| **합계** | **7,000** | **900** | |

평가 input이 큰 이유:
- 회사 인재상·직무 루브릭·few-shot 채점 사례를 모두 시스템에 주입해야
  "그렇습니다 → 72점" 같은 회피 답변 고득점 문제를 차단할 수 있다.

평가 output이 큰 이유:
- 5축(논리성/직무적합성/구체성/표현력/차별성) 각각의 점수 + 점수 근거
  + 개선점 + 모범답안 + 총평을 요구하기 때문.

| Claude Haiku 4.5 | $0.00920 | $0.00488 |
| Claude Sonnet 4.6 | $0.03600 | **$0.02160** |
| Claude Opus 4.7 | $0.17250 | $0.10125 |

¹ 캐시 적용: 5,000 tokens(컨텍스트+루브릭+few-shot) cached, 2,000 fresh.

### 계산식 예시 — Sonnet 4.6, 캐시 적용
```
cached input : 5,000 × $0.30 /1M = $0.00150
fresh input  : 2,000 × $3.00 /1M = $0.00600
output       :   900 × $15.00/1M = $0.01350
                                = $0.02100
```

## 4. 사용자 1명 월간 비용 (월 50라운드 가정)

| 경로 | 우리 인프라 부담 | 사용자 추가 결제 | 부담 주체 |
|---|---:|---:|---|
| **MCP + Claude Pro** | **$0** | **$0** (정액 $20에서 차감, 50라운드는 Claude Pro quota의 ~5%) | 사용자 (이미 결제 중) |
| Bedrock Haiku 3 (무료 티어) | $0.144 | $0 | 우리 |
| Bedrock Sonnet 4.6 + 캐시 (프리미엄) | $1.080 | $0 | 우리 |

> Claude Pro의 메시지 quota는 시간당/5시간 기준 변동이지만, 면접 1라운드 =
> Claude 측 메시지 1~2회이므로 정액 사용자가 자주 면접을 봐도 안에서 해결됨.

## 6. 권장 비즈니스 모델

```
무료 티어    : Bedrock Haiku 3 / 월 30라운드 제한
              사용자 1명당 우리 부담 ~$0.087
              
연결 티어    : MCP (Claude Pro 본인 구독 활용)
              무제한 사용 / 우리 부담 $0
              사용자는 이미 Claude Pro에 $20 결제 중

프리미엄 티어 : Bedrock Sonnet 4.6 + cache / 월 정액 $5
              사용자 1명당 우리 부담 $1.08
              마진 ~$3.92/명
```

### 1,000 active user 시점 시뮬레이션 (균등 분포 가정)

- 무료 400명 × $0.087 = $34.8/월 (우리 부담)
- MCP 300명 × $0 = $0
- 프리미엄 300명 × ($5 - $1.08) = +$1,176/월 (수익)

→ **순이익 ≈ $1,141/월** (인프라·도메인·운영 제외)

## 7. 가정에 대한 검증 포인트

1. **월 50라운드/사용자**: active 사용자 정의에 따라 달라짐. 실측 데이터로 보정 필요.
2. **input 7,000 tokens**: Phase 2 평가 시스템 재설계로 +1,500 (few-shot 강화)되어 ~8,500이 될 수 있음 → 라운드당 +20%.
3. **cache 적중률 80%**: 동일 회사·직무·면접유형 조합이 5분 안에 재사용될 빈도. 트래픽 적을 땐 50% 이하일 수 있음.
4. **Bedrock 단가**: Anthropic 공식 가격과 동등이라 가정. region별 차이 있을 수 있음.
